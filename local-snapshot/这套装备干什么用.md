# 这套装备干什么用（2026-11-03 的结论）

## 一句话

这是一个**完整攻击链**的工具箱。「攻击网站」只是第一环，装备的大半是「进去之后」用的。

## 六步链条

```text
① 找目标   fofa-recon / passive-recon / recon-pipeline / asset-correlation
② 探入口   active-scan(nmap/masscan) / nuclei / dirsearch / web-fingerprint
③ 打进去   unauth-exploit / credential-attack(hydra)
④ 拿到手   shell-handler / vps-reverse-shell / webshell-toolkit(冰蝎)
⑤ 往外走   suo5 / chisel / frp / ligolo / cn-proxy-pool
⑥ 往里推   fscan / gogo / lateral-movement(Impacket) / hashcat / john
```

**①②③ 是打网站，⑤⑥ 占了装备一半还多，全是内网。** 只做网站的话，前两步加 nuclei 就够，后面那半用不上。

## 三类真实用途

| 用途 | 谁在用 | 用哪几步 |
| --- | --- | --- |
| 授权渗透 / 红队演练 | 安全公司、政企年度演练 | ①→⑥ 全链 |
| **自有资产体检** | 独立开发者、运维、小团队 | ①②，最多加 ③ |
| 漏洞研究 / CTF / 复现 Nday | 研究员、打比赛 | ②③ + searchsploit + nuclei |

对本人（AI 出海独立开发者）最实际的是第二类，每月给自己的域名跑一遍：

- `fofa` —— 查自己域名下有没有不知道的子域（测试环境忘关、`.git` 暴露、后台默认口令，这是独立开发者最常见的三个入口）
- `nuclei` —— 跑 CVE 模板，看框架版本有没有已知洞
- `dirsearch` / `ffuf` —— 扫备份文件（`www.zip`、`backup.sql`），拖库事故的高发原因
- `whatweb` / `gowitness` —— 批量截图，看服务有没有被挂马、被劫持

## 四项待补的处置：全部不配，但理由各不相同

| 项 | 能不能简单配 | 结论 | 原因 |
| --- | --- | --- | --- |
| `FOFA_KEY` | 能，粘一行就生效 | **不配** | 手上没有 key。不填则 `fofa-recon` 降级为 crt.sh + subfinder/ksubdomain + 被动 DNS，视野小但能用 |
| VPS（落地机） | 能，但**选哪台是生产决策** | **不配** | 见下一节：现有机器的探活结果里，通的两台都是业务机 |
| `msfconsole` | 不能 | **不配** | Homebrew cask 因 Gatekeeper 在 2026-09-01 被禁用，官方只发 Linux 包；本机有 nc/socat/suo5/chisel 可替代 |
| `Godzilla` 哥斯拉 | 不能 | **不配** | 无官方公开仓库（GitHub 只有反编译变体），不从不明源拉 jar；冰蝎 4.1 已装，两者功能重叠 |

`AntSword` 蚁剑同样不装：技能里写死 `linux-x64` 路径，mac 要另取 mac 包且得改路径，属可选。

## 为什么现成的服务器没有直接拿来当落地机

对 `~/.ssh/config` 里的 5 台候选做了只读探活（`ssh 'echo ok'`）：

- **2 台连通**：分别是游戏中继机、办公室看板服务器。都是 Linux + nc/tmux/python3。
- 1 台密钥不匹配（publickey denied），2 台登录后 shell 报错。

**没有一台适合做红队落地机**，因为：

1. 它们都是**生产业务机**。在业务机上开 9000–9999 监听、落载荷、存反弹 Shell 私钥，等于给生产加攻击面。
2. 云安全组要为这段端口放行，流量特征会被云厂商的安全产品盯上，可能连带影响正常业务告警。
3. 演练结束要清理残留，生产机上的清理遗漏代价高。

标准做法是**单开一台按量付费小机**（1C1G，月成本几十元），专门做演练落地，练完直接销毁。等真要做内网演练时再开，现在配了也是闲置。

## 不配也能做的事

| 能做完 | 做不完 |
| --- | --- |
| 给自己域名跑完整资产面 + 指纹 + 漏洞检测 | 进不了内网（差 VPS 出口 + FOFA 视野） |
| 扫端口、认服务、查 CVE、找暴露文件 | 拿不到持续会话（反弹 Shell 没人接） |
| 本地靶场（Vulhub/DVWA）、CTF 全链走一遍 | 域渗透（没有 Windows 目标环境） |
| 复现 Nday、验证 PoC、出报告 | 大规模扫描（单机工具，不是扫描平台） |

## 已配好的东西（顺手补的）

- **字典** `toolkit/wordlists/`：`common.txt`、`raft-small-words.txt`、`raft-small-dirs.txt`、`users-top.txt`，来自 SecLists。没有字典，ffuf / dirsearch / gobuster 都是空转。
- **nuclei 模板** 14104 个，实体在 `~/.local/nuclei-templates`。
- **地区门禁**：`lib/net-scope.js` 默认禁止中国大陆、香港、澳门网段，只放行登记过的那一台自有服务器；密钥、密码、网段、通配符都不加例外。
- **演练台授权**：右侧栏「演练台」首次进入要读声明、等倒计时、勾三项。

## 将来真要落地时的最短路径

```sh
# 1. 开一台按量小机（Ubuntu 22.04+），安全组放 9000-9999
# 2. 私钥放这里并锁权限
install -m 600 /path/to/key ~/.dsh/redteam/toolkit/vps/id_rsa
# 3. 填两行
printf 'REDTEAM_VPS_HOST=ubuntu@<新机器IP>\nREDTEAM_VPS_KEY=%s\n' \
  "$HOME/.dsh/redteam/toolkit/vps/id_rsa" >> ~/.dsh/.env
# 4. 验通道
~/.dsh/redteam/toolkit/vps/vps.sh status
```

FOFA 要补时：`https://fofa.info/userInfo` 拿 key，填进 `~/.dsh/.env` 的 `FOFA_KEY=`（空位已留，文件权限 600）。
